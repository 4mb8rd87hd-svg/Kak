# Как по маслу!

Мобильный каталог продуктов и полуфабрикатов с корзиной, формой заявки и админкой для редактирования карточек. Интерфейс — статический сайт для GitHub Pages; защищённое API и уведомления владельцу — Cloudflare Worker + KV. Внешние библиотеки для сборки не нужны.

## Что уже есть 

- Адаптивная витрина на русском языке, категории, поиск, избранное и корзина.
- Карточки с названием, категорией, ценой, фасовкой, описанием и фото. В админке товар можно временно отметить как отсутствующий: витрина показывает статус вместо цены, а добавление в корзину и отправка заказа с таким товаром блокируются. Фото при загрузке сжимаются в браузере.
- Массовый импорт до 100 товаров: по одной строке `Название; цена; категория; фасовка` (категория и фасовка необязательны) либо `Название — цена`.
- Отдельные разделы «Категории», «Хиты» и «Акции» в админке: категории сохраняются отдельно, хиты закрепляются на главной, а акционные товары видны в специальном разделе витрины. Для скидки можно указать старую цену.
- Адрес магазина в Арзамасе и телефон для звонка размещены в профиле; изменить их можно в контактной карточке `index.html`. Заявка собирает имя, адрес доставки, телефон, товары и комментарий; адрес запоминается в браузере для следующего заказа. Оплаты нет: владелец получает сообщение в Telegram и звонит покупателю.
- Ссылка на админ-панель показывается только после проверки Telegram-аккаунта владельца; Worker разрешает менять каталог только ID из `ADMIN_TELEGRAM_ID`.
- Без настроенного API приложение запускается в демо-режиме: каталог и заявки хранятся только в текущем браузере, уведомления продавцу не отправляются.

## 1. Опубликовать витрину на GitHub Pages

1. Загрузите файлы проекта в GitHub-репозиторий. Для GitHub Pages на бесплатном тарифе репозиторий должен быть публичным; секретов в нём нет — токен хранится только в Cloudflare.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
4. Дождитесь адреса сайта вида `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

GitHub Pages хостит только витрину. Токен Telegram-бота нельзя класть в этот репозиторий или в `app.js`.

## 2. Создать бесплатный API на Cloudflare

1. Создайте бесплатный аккаунт Cloudflare и установите Wrangler на компьютере с Node.js: `npm install -g wrangler`.
2. Войдите: `wrangler login`.
3. В корне проекта создайте KV-хранилище: `wrangler kv namespace create CATALOG`.
4. Скопируйте выданный `id` в `wrangler.toml` вместо `REPLACE_WITH_YOUR_KV_NAMESPACE_ID`.
5. Создайте Telegram-бота у [@BotFather](https://t.me/BotFather). Узнайте числовой Telegram ID владельца (например, через бота `@userinfobot`). Это ID, не `@username`.
6. В корне проекта задайте секреты Worker:
   - `wrangler secret put BOT_TOKEN` — введите токен, полученный у @BotFather.
   - `wrangler secret put ADMIN_TELEGRAM_ID` — введите числовой Telegram ID владельца.
   Значения вводятся в запрос Wrangler и не добавляются в файлы или GitHub.
7. Опубликуйте Worker командой `wrangler deploy`. Сохраните адрес вида `https://kak-po-maslu-api.ВАШ-АККАУНТ.workers.dev`.
8. В `app.js` замените пустое значение `API_BASE_URL` на адрес Worker, без завершающего `/`, и снова отправьте изменения в GitHub.

У бесплатного Cloudflare Workers есть лимиты запросов и KV-записей. Для небольшого локального магазина обычно достаточно; актуальные лимиты зависят от тарифов Cloudflare.

## 3. Подключить мини-приложение к Telegram

1. Убедитесь, что `BOT_TOKEN` добавлен в Cloudflare Worker как Secret. Cron-задача Worker раз в минуту подключает webhook к Telegram, только если у бота ещё нет другого webhook; существующий webhook не перезаписывается.
2. Отправьте боту `/start`. Worker ответит кнопкой «Открыть магазин»; нажмите её, чтобы открыть мини-приложение внутри Telegram. Если у бота уже настроен webhook на другой адрес, его владелец должен перенастроить webhook.
3. Владелец должен сам открыть бота и нажать **Start**, чтобы бот мог присылать ему заявки.
4. В профиле магазина откройте админ-панель: во вкладке «Категории» добавляйте разделы, в «Товарах» создавайте позиции, во вкладке «Хиты» закрепляйте товары на главной, а в «Акциях» выбирайте товары для промо-раздела. Скидочную цену задайте при редактировании товара, указав старую цену выше текущей.

`ADMIN_TELEGRAM_ID` должен быть числовым Telegram ID владельца, а не username. Worker проверяет подпись Telegram `initData` и срок её действия перед админскими изменениями и отправкой заказов.

## Проверка перед запуском

- Откройте `https://АДРЕС-WORKER/api/health` — ожидается `{"ok":true}`.
- В мини-приложении добавьте тестовый товар, отправьте заявку со своим номером и убедитесь, что сообщение пришло владельцу.
- Если сайт открыт вне Telegram, реальные заявки не отправятся: для проверки заказов нужно запускать мини-приложение через Telegram.
